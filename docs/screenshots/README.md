# Screenshots

The screenshots shown in the main [README](../../README.md) live in this folder.

Guidelines for adding or refreshing one:

- PNG, 1920x1080 for TV screens, native size for the phone app.
- No personal data: no real channel list, no private library names, no account names.
- Use only media you own or free wallpapers.
- Name files by what they show, for example `home.png`, `settings.png`, `remote.png`.

## Files

| File | Shows |
| --- | --- |
| `home.png` | TV home screen with hero and tile rows |
| `settings.png` | Settings screen |
| `theme-midnight.png` | Home screen with the Midnight mod theme |
| `live-tv.png` | Live TV with the now and next guide |
| `library.png` | Local media library |
| `mods-catalog.png` | Mod store: category chips, search and cards (5 per row) |
| `mods-detail.png` | Detail of a mod (shown with the French interface): banner, publisher, dependencies, permissions, personal rating |
| `mods-gallery.png` | Gallery of several mods in the store |
| `remote-ring.png` | Phone remote, ring mode (Google TV style) with volume bar |
| `remote-mods.png` | Phone remote, Mods tab with button panels from a mod |
| `remote-neon.png` | Phone remote with a neon theme |
| `remote-amoled.png` | Phone remote with the AMOLED theme |
| `remote-settings.png` | Phone remote settings sheet (theme choice) |
| `remote.png` | Phone remote screenshot taken before the v1.1.0 images (the ring screenshots above are the current ones) |

The phone remote mod screenshots come from a browser rendering of the phone app talking to the real PC protocol, not from a physical phone.
